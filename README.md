📌 Portfolio Website (HTML & CSS)

This repository contains a simple personal portfolio website created using HTML and CSS. It is suitable for beginners who are starting with web development.

📁 Files in This Repository
1️⃣ HEY.HTML

This is the main HTML file of the portfolio.

It contains the structure and content of the website.

Sections typically include:

Name and introduction

About section

Education / skills

Image display

This file links to the CSS file for styling.

2️⃣ style.css

This file contains all the styling rules for the website.

It controls:

Colors

Fonts

Layout

Spacing

Image styling (including borders and alignment)

The CSS file helps make the website visually attractive and responsive.

3️⃣ ayanshu.jpg

This is the profile image used in the portfolio.

It is displayed in the HTML file.

Styled using CSS (for example: round border or fixed size).

🚀 How to Run the Project

Download or clone this repository.

Open the folder.

Double-click on HEY.HTML
OR

Open HEY.HTML in any web browser (Chrome, Edge, Firefox).

🛠 Technologies Used

HTML5

CSS3

🎯 Purpose of This Project

Practice basic HTML structure

Learn CSS styling

Create a beginner-level portfolio website
